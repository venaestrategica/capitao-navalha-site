# Capitão Navalha – página /clube

Cópia estática da página https://www.capitaonavalhabarbearia.com.br/clube (originalmente no Great Pages).

- `index.html` – página (HTML original, com links trocados para arquivos locais)
- `assets/style.css`, `assets/main.js` – CSS e JS da página
- `assets/img/`, `assets/editor/` – imagens
- `vercel.json` / `netlify.toml` – fazem `/clube` abrir a página

Rodar localmente: `python3 -m http.server 8080` e abrir http://localhost:8080/clube
